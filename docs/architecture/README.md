# 架构说明

单体应用，没拆微服务 —— 这个规模不需要。React 做界面，FastAPI 管接口和 Agent，PostgreSQL 存数据。

## 模块划分

```text
frontend/src/features/agent         Agent 对话与工作区
frontend/src/features/profile       个人档案
frontend/src/features/programs      项目、对比与证据
frontend/src/features/applications  申请看板与任务

backend/app/agent                    Agent 执行循环和模型适配
backend/app/harness                  工具校验、权限和执行
backend/app/research                 读官网、抽字段、校验原文
backend/app/tools                    Agent 工具适配
backend/app/modules/profiles         个人档案领域
backend/app/modules/programs         项目与证据领域
backend/app/modules/applications     申请与任务领域
backend/app/modules/agent_runs       运行记录与对话历史
```

API 和 Agent 工具都调用同一套领域服务，不能直接修改数据库。这样可以保证网页操作与 Agent 操作遵守相同的校验、事务和权限规则。

## 个人档案

档案保存教育背景、GPA、IELTS、经历、预算和目标。字段历史同时记录来源与验证状态：用户亲自填写的数据标记为用户确认，Agent 提取的数据在用户确认前保持未验证。

档案更新在一次事务中完成。GPA、GPA 满分和 IELTS 属于关键成绩字段，Agent 修改这些字段前必须请求用户确认。

## 项目与证据

项目要求和证据分开保存：

- 项目要求保存当前对外展示的值。
- 证据保存官网链接、采集时间、来源类型和验证状态。
- 申请季是要求主键的一部分，避免不同年份的数据混在一起。

新证据与当前值一致时，只补充证据；不一致时保留原值，并把该要求标记为待复核。管理员接受或拒绝冲突后都会写入审计记录。

项目种子只包含学校、项目、地区和方向标签，不编造语言成绩、截止日期或学费。预算筛选只比较相同币种，不使用没有来源的汇率。

## 申请与任务

每个用户、项目和申请季只能创建一条申请。申请状态由状态机控制，不能跳过必要步骤。

进入“待提交”前，所有必要任务都必须完成。提交、撤回和删除属于高风险操作；Agent 还会把录取和拒绝结果视为高风险，防止模型误写现实结果。

申请和任务使用版本号检测并发修改。客户端拿旧版本更新时会收到冲突提示，而不是覆盖较新的数据。

## Agent 执行流程

```text
模型提出工具调用
  → 校验工具名和参数
  → 根据当前用户与调用内容判断风险
  → 执行领域服务或等待用户确认
  → 把结构化结果返回模型
  → 模型继续调用工具或生成最终回答
```

Agent 运行有步骤和工具次数上限，防止无限循环。身份来自登录上下文，模型不能通过工具参数伪造用户 ID 或管理员权限。

一轮模型回复可能包含多个工具调用。只要其中一个需要确认，整批调用都会暂停，避免只执行一半后留下无法继续的对话。用户批准时继续原来的调用批次，而不是让模型重新生成；批准只对本次恢复有效。

## 对话与运行记录

每次用户提问对应一条独立运行记录，同一会话可以包含多次运行。数据库保存用户可见的问题、回答、状态、次数和安全的执行事件，因此刷新页面后可以恢复对话和最近活动。

运行记录不保存思维链、隐藏推理、工具参数、工具输出或系统提示词。记录失败不会回滚已经完成的业务操作，但会留下可观测性错误，方便排查。

当前暂停状态保存在进程内存中，适合单实例演示。如果部署多个后端实例，需要把暂停状态迁移到共享存储。

## 评测

评测分为两层：

- 确定性评测使用脚本提供工具调用，验证参数校验、权限、人工确认、状态流转、错误恢复和最终业务结果。
- 真实模型评测让模型自行选择工具，用于观察工具选择、参数错误和冗余调用。

两类结果不能混为一个分数：确定性评测说明运行框架是否正确，真实模型评测才反映模型选择工具的能力。当前数据集包含 38 个确定性场景，其中 13 个也可用于真实模型评测。

## 当前限制

- 暂停中的 Agent 状态尚未写入共享存储，不支持多实例无状态恢复。
- 院校网页抓取和定时更新尚未接入后台任务，证据通过受控导入进入系统。
- 没有来源的要求和汇率不会自动补全。
- 真实模型效果受模型服务、网络和提示词影响，需要持续通过评测数据改进。
